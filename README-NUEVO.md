## 👨‍💻 Sobre el Proyecto

Portafolio web profesional desarrollado con Angular 16 y Tailwind CSS, diseñado para mostrar mi experiencia como Desarrollador Full Stack Senior. El sitio presenta mis proyectos, habilidades técnicas y experiencia profesional de manera moderna y responsiva.

## ✨ Características

- **🎨 Diseño Moderno**: UI/UX atractivo con animaciones fluidas
- **📱 Responsive Design**: Optimizado para dispositivos móviles y desktop
- **⚡ Alto Rendimiento**: Aplicación SPA optimizada con lazy loading
- **🔍 SEO Optimizado**: Metadatos y estructura semántica
- **🌟 Animaciones**: Transiciones y efectos visuales profesionales
- **🎯 Navegación Intuitiva**: UX enfocado en la experiencia del usuario

## 🚀 Instalación y Uso

### Prerrequisitos
- Node.js 18+ 
- npm 9+
- Angular CLI 16+

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/HectorARG/portafolio-web-angular.git

# Navegar al directorio
cd portafolio-web-angular

# Instalar dependencias
npm install

# Ejecutar servidor de desarrollo
npm start
```

La aplicación estará disponible en `http://localhost:4200`

### Scripts Disponibles

```bash
# Servidor de desarrollo
npm start

# Build para producción
npm run build

# Ejecutar tests
npm test

# Build con observador
npm run watch
```
